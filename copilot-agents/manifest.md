# Copilot Agent Manifest

This folder contains implementation-ready prompt packs for GitHub Copilot custom agents focused on AWS CDK with TypeScript.

## Phase 1 essential personas
- `cloud-architect.md`
- `cloud-developer.md`
- `cloud-reviewer.md`
- `cloud-tester.md`
- `cloud-verifier.md`
- `cloud-debugger.md`
- `cloud-finops.md`
- `construct-creator.md`
- `cloud-security.md`
- `identity-and-access-advisor.md`
- `observability-engineer.md`

## Phase 2 optional personas
- `cloud-operations.md`
- `cloud-sre.md`
- `resilience-engineer.md`
- `migration-advisor.md`
- `documentation-assistant.md`

## Standard prompt-pack structure
Each file includes:
1. Mission
2. Primary users
3. Best for
4. Avoid using when
5. Scope of responsibility
6. AWS CDK TypeScript focus areas
7. Knowledge routing logic
8. System prompt
9. Developer prompt
10. User invocation examples
11. Response style
12. Escalation rules
13. Guardrails
